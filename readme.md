# My Net Scan

Docker-контейнер с Python-скриптом для сканирования портов и подключения к сервисам (SSH, RDP, VNC, Telnet) с использованием nmap и вспомогательных утилит.

## Описание

Скрипт сканирует все порты указанного IP адреса, определяет открытые сервисы и пытается подключиться к ним с учётом заданных учётных данных.

## Требования

- Docker
- IP адрес целевого хоста
- Логин и пароль для подключения

## Сборка образа

Скопируйте `your_script.py` и `Dockerfile` в одну папку и выполните:

docker build -t my-net-scan .

text

## Запуск контейнера

docker run --rm my-net-scan <ip> <логин> <пароль>

text

Пример:

docker run --rm my-net-scan 192.168.1.100 admin password123

	
## Установленные утилиты внутри контейнера

- nmap
- sshpass
- xfreerdp (RDP клиент)
- tigervnc-viewer (VNC клиент)
- telnet
